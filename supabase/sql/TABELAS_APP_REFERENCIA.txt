--- Como usar este ficheiro ---
1) Correr user_persona_complete_setup.sql para resolver colunas em falta no perfil.

   ou gerar migração nova a partir das colunas em utils/supabaseSelectColumns.ts e dos .insert/.upsert no código.
3) Evitar DROP CASCADE em produção; preferir ADD COLUMN IF NOT EXISTS e CREATE TABLE IF NOT EXISTS como nos scripts notes_*.
